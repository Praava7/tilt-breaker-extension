Tilt Breaker - Chess Tilt Prevention Extension
Project Overview
A browser extension that helps chess players manage tilt by automatically detecting consecutive losses on Lichess.org and providing intervention mechanisms to prevent emotional decision-making that leads to rating drops and poor play quality.
Core Functionality
Automatic Game Tracking:

Monitors chess games on Lichess in real-time
Detects game results (win/loss/draw) by analyzing DOM content
Tracks consecutive loss streaks and session statistics
Maintains session data with automatic cleanup

Tilt Intervention System:

Triggers alerts after configurable consecutive losses (default: 3)
Presents two-choice intervention popup: "One more game" or "Take a break"
Forces site closure if user loses after choosing "one more game"
Implements cooldown periods with activity suggestions

Session Management:

Automatically starts new sessions
Resets data on browser close, tab inactivity, or after 24 hours
No persistent lifetime statistics to encourage fresh starts

Current Development Status

Known Limitations Requiring Resolution:
Technical Issues:

Player color detection reliability (currently assumes white pieces)
Game result parsing depends on specific DOM text patterns
Chrome storage vs localStorage inconsistencies across components
Extension context invalidation during development cycles

Robustness Gaps:

Limited board theme compatibility testing
Insufficient fallback methods for game detection
No error reporting or diagnostic logging
Vulnerable to Lichess interface changes

Cross-Platform Constraints:

Chrome/Edge only (Manifest V3)
Requires Firefox conversion for broader compatibility
Missing Safari support entirely

Quality Assurance Needs:

Target Outcome
A reliable, cross-browser extension that demonstrably helps chess players avoid tilt-induced rating loss by providing timely, effective interventions during consecutive loss streaks. The extension should operate transparently without affecting normal gameplay while providing measurable tilt prevention benefits.
The project represents a practical application of behavioral intervention technology to competitive gaming, with potential applicability to other skill-based online activities where emotional regulation affects performance.
